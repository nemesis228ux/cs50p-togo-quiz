🌟 Aperçu des Problem Sets (Psets)

Chaque Problem Set m'a permis d'explorer des concepts fondamentaux de la programmation moderne :

Pset 0 & 1 : Prise en main de l'environnement, création de fonctions personnalisées et logique conditionnelle.

Pset 2 & 3 : Automatisation des tâches répétitives avec les boucles et sécurisation du code face aux erreurs de saisie utilisateur (exceptions).

Pset 4 & 5 : Utilisation de modules externes et mise en place de tests unitaires rigoureux avec pytest pour garantir la fiabilité du code.

Pset 6 & 7 : Manipulation de fichiers externes (lecture/écriture) et validation de formats complexes grâce aux expressions régulières (Regex).

Pset 8 : Introduction aux concepts de la Programmation Orientée Objet (POO) en Python.

🏆 Projet Final : Togo Quiz (togo-quiz)

Pour valider le cours, j'ai conçu et développé Togo Quiz, une application interactive en ligne de commande (CLI) en Python.

Description : Un quiz dynamique qui teste les connaissances sur l'histoire, la géographie, la culture et la politique du Togo.

Fonctionnalités clés :

Affichage visuel en ASCII Art (pyfiglet).

Chargement dynamique des questions depuis une base de données externe (quiz.json).

Gestion d'un chronomètre pour chaque question (time).

Mise en forme propre des choix sous forme de tableau (tabulate).

Suite de tests unitaires validée avec pytest.

🛠️ Technologies Utilisées

Langage : Python 3

Outils & Bibliothèques : pytest, pyfiglet, tabulate, Git / GitHub

Environnement : VS Code / Linux (Ubuntu)
